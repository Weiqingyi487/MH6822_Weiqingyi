## Project Overview

This project proposes a jurisdiction-aware governance and compliance tool for AI-driven lending systems operating across the United States and the European Union.

The system is designed to support multinational financial institutions in managing regulatory divergence in AI-based credit scoring and lending decisions. It applies different governance workflows according to jurisdiction-specific regulatory requirements, particularly focusing on explainability, fairness assessment, human oversight, and compliance escalation mechanisms.
